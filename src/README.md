## Binary Search Trees

Converts an array of data into a binary search tree, with each left node being lower than each right node. It is specifically a balanced binary search tree, of which the difference between the heights of each left and right subtrees of every node is no greater than one.

## Features
###Breadth-first traversal
- levelOrderForEach()

###Depth-order traversal
- inOrderForEach()
- preOrderForEach()
- postOrderForEach()
