## Binary Search Trees

Converts an array into a binary search tree, with each left node being lower than each right node. It is also a balanced binary search tree, of which the difference between the heights of each left and right subtrees of every node is no greater than one. (the Odin Project curriculum: https://www.theodinproject.com/lessons/javascript-binary-search-trees)

## Features

### Types of Search
**Breadth-first traversal**
- levelOrderForEach()

**Depth-order traversal**
- inOrderForEach()
- preOrderForEach()
- postOrderForEach()

## Other methods
- height(value)
- depth(value)
- isBalanced()
- reBalance()
- includes(value)
- insert(value)
- deleteItem(object, value)
